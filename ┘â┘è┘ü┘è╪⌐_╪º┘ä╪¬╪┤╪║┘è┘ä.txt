🚀 كيفية تشغيل نظام إدارة المستأجرين كبرنامج سطح مكتب
==========================================================

🖥️ التشغيل كتطبيق سطح مكتب (الأفضل):

1️⃣ التشغيل السريع (الأسهل):
   Windows: انقر مرتين على "تشغيل_البرنامج.bat"
   Mac/Linux: انقر مرتين على "تشغيل_البرنامج.sh"

2️⃣ التشغيل المتقدم:
   Windows: START.bat
   Mac/Linux: ./START.sh

3️⃣ من سطر الأوامر:
   python main.py
   أو
   python desktop_app.py
   أو
   python run_desktop_app.py

🌐 التشغيل كموقع ويب (إضافي):
   python simple_run.py
   ثم افتح: http://localhost:8080

📱 ما ستحصل عليه:
   ✅ نافذة برنامج مستقلة
   ✅ لا حاجة لفتح المتصفح
   ✅ واجهة سطح مكتب احترافية
   ✅ سهولة في الاستخدام

⚠️ إذا واجهت مشاكل:
   1. تأكد من تثبيت Python 3.8+
   2. شغل: pip install -r requirements.txt
   3. شغل: pip install pywebview
   4. اقرأ ملف RUN_INSTRUCTIONS.md للتفاصيل

🎯 الملفات المهمة:
   - تشغيل_البرنامج.bat/sh : تشغيل كامل للبرنامج
   - START.bat/sh : تشغيل سريع
   - main.py : ملف التطبيق الرئيسي
   - desktop_app.py : تطبيق سطح المكتب
   - run_desktop_app.py : مشغل متقدم للتطبيق
