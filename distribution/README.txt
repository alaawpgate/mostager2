# نظام إدارة المستأجرين - إصدار Windows

## الوضع الحالي:
هذا مجلد تجريبي للتوضيح. الملف التنفيذي الحقيقي سيظهر هنا بعد تشغيل عملية البناء.

## كيفية إنشاء الملف التنفيذي:

### الخطوات المطلوبة:
1. **انسخ المشروع إلى جهاز Windows**
2. **تأكد من تثبيت Python 3.8 أو أحدث**
3. **افتح Command Prompt كمدير**
4. **انتقل إلى مجلد المشروع:**
   ```cmd
   cd "C:\path\to\mostager-3"
   ```
5. **شغل ملف البناء:**
   ```cmd
   build_exe.bat
   ```

### ما سيحدث:
- سيتم تثبيت PyInstaller تلقائياً
- سيتم بناء الملف التنفيذي (قد يستغرق 5-10 دقائق)
- سيظهر ملف `mostager.exe` في هذا المجلد
- سيتم نسخ قاعدة البيانات والملفات المطلوبة

### الملفات التي ستظهر بعد البناء:
- `mostager.exe` - الملف التنفيذي الرئيسي
- `database.db` - قاعدة البيانات
- `README.txt` - دليل الاستخدام
- `run_mostager.bat` - ملف تشغيل مساعد

### متطلبات النظام المستهدف:
- Windows 10 أو أحدث
- 4 GB RAM (الحد الأدنى)
- 100 MB مساحة فارغة
- اتصال بالإنترنت (لخدمة WhatsApp)

### استكشاف الأخطاء:
إذا واجهت مشاكل:
1. تأكد من تشغيل Command Prompt كمدير
2. عطل برامج مكافحة الفيروسات مؤقتاً
3. تأكد من الاتصال بالإنترنت
4. تحقق من ملف `mostager.log` للأخطاء

### الدعم الفني:
- تحقق من ملف `BUILD_INSTRUCTIONS.md` للتفاصيل الكاملة
- راجع ملف `README_EXE.md` للدليل المبسط
